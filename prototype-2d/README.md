# Echoes of Keru

A tiny, playable 2D platformer about a penguin exploring ancient ruins across three connected levels.

## Run it

```bash
npm run dev
```

Then open [http://localhost:4173](http://localhost:4173).

## Controls

- `A` / `D` or arrow keys: move
- `Space`, `W`, or `↑`: jump and double-jump
- `Shift`: air dash
- `R`: reset the expedition

The expedition now has three zones: The Drowned Steps, The Bell Gallery, and The Blue Archive. Each zone has its own background track and three lantern shards to collect.

The game ships with its penguin sprite frames in `assets/penguin/`. Audio provenance is documented in [credits.md](credits.md); all downloaded tracks and effects are marked CC0 on their source pages.

The broader campaign plan is tracked in the repository [roadmap](../roadmap.md).
