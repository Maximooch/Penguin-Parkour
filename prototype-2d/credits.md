# Audio credits

All downloaded audio in this prototype came from OpenGameArt.org pages that list the files as CC0. The source pages and the local filenames are recorded here so the pack stays auditable.

## Music

- **Drowned Steps** — `assets/audio/music/drowned-steps.ogg` — [Telos Ruins Creepy](https://opengameart.org/content/telos-ruins-creepy) by Tozan. The source page lists the music as CC0.
- **Bell Gallery** — `assets/audio/music/bell-gallery.ogg` — [Loopable Dungeon Ambience](https://lpc.opengameart.org/content/loopable-dungeon-ambience) by JaggedStone. The source page lists the ambience as CC0.
- **Blue Archive** — `assets/audio/music/blue-archive.ogg` — [Lost in a bad place](https://opengameart.org/content/lost-in-a-bad-place-horror-ambience-loop) by congusbongus. The source page lists the music as CC0.

## Sound effects

- **Jump** — `assets/audio/sfx/jump.wav` — [Jump and Landing](https://opengameart.org/content/jump-landing) by Macro / sound by Dan Knoflicek. The source page lists the files as CC0 and asks for credit, so the credit is preserved here.
- **Landing** — `assets/audio/sfx/land.wav` — [Jump Landing Sound](https://opengameart.org/content/jump-landing-sound) by MentalSanityOff, submitted by qubodup. The source page lists the file as CC0.

The game also uses short Web Audio tones for shard collection, double-jump, dash, and door transitions; those are generated locally in `game.js`.
